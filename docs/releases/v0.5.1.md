The first release of PaperKnife for Android: edit the text of your PDFs on your phone or tablet,
offline.

## What it does

- **Edit text in place.** Tap any text to select its line or table cell, type, and tap Apply.
  PaperKnife keeps the original font, size, position and color, and changes only the characters
  you changed.
- **Verified edits.** After every edit PaperKnife reads the result again and compares the whole
  page; if anything else would change, it refuses the edit and says why, instead of damaging the
  document.
- **Hard PDFs too.** PDFs that draw every letter on its own (a tap selects the whole line, not one
  letter), PDFs saved from browsers, and LaTeX PDFs, where PaperKnife can even add letters the
  PDF's fonts didn't contain.
- **Pages.** Rotate, delete and add pages from another PDF. Undo and redo, and save a copy.
- **Private.** No uploads, no account, no telemetry, and no `INTERNET` permission: Android itself
  keeps PaperKnife offline.

PaperKnife for Android runs the engine of
[PaperKnife for Windows 0.5.1](https://github.com/shivam098/paperknife-windows/releases/tag/v0.5.1),
ported line by line, and passes the same 128 conformance tests, also on Android itself, so it edits
the same PDFs the same way.

## Install

| File | What it is |
|---|---|
| `PaperKnife-0.5.1-android.apk` | The app, for every Android phone and tablet with Android 8.0 or later. |
| `SHA256SUMS.txt` | Its checksum. |

On your phone or tablet, download the APK and open it. Android asks you to allow installing apps
from your browser or Files app the first time; allow it, then select **Install**. If Play Protect
says it doesn't recognize the app, select **More details**, then **Install anyway**. Every release
is signed with the same key, so later versions install over this one.

The APK is about 100 MB: it includes PDFium for every kind of processor and LaTeX's fonts, which
PaperKnife adds letters from.

## Known limits

PaperKnife refuses an edit rather than damage your document. In this version it can't:

- add characters that the PDF's font doesn't contain, except in LaTeX's Computer Modern, Latin
  Modern and CM-Super fonts (with the limits the
  [Windows release notes](https://github.com/shivam098/paperknife-windows/releases/tag/v0.5.1)
  describe);
- keep centered text centered: the edited text starts where the old text started;
- edit some pages of encrypted PDFs, which are edited by rewriting the whole page;
- edit a line as one piece when the PDF splits it across fonts, for example the "fi" in
  "Confirmed" in PDFs saved from Chrome; each piece can be edited on its own;
- edit scripts that need text shaping (such as Hindi or Arabic), add line breaks, or edit scanned
  pages;
- reorder, extract or merge pages, or zoom by pinching, yet (zoom is in the menu);
- keep unsaved changes if Android stops PaperKnife in the background: save a copy before you
  switch to other apps for long.

This is an early preview: keep a backup of any document you can't afford to lose, and please
[report problems](https://github.com/shivam098/paperknife-android/issues).
